# Drawing2Data-Bench

This repository consists of tools for sythetic data generation, and model training and benchmarking.

# Installation

To install the repo, clone it and run the command in the repo:
```bash
pip install -r requirements.txt
```

Requirements:
 * Linux (tested on Ubuntu 26.04 LTS)

# Generation

All relevant files are in the `generation` directory.

# Model training

All relevant files are in the `extraction` directory.

# Benchmarking

All relevant files are in the `benchmarks` directory.
